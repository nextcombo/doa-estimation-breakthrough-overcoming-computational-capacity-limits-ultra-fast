III. Introduction The problem of spectrogram estimation (LSE) has received widespread attention in research for over 40 years. Its core reason lies in the fact that many fundamental problems in signal processing can be transformed into spectrogram estimation problems, such as wave direction estimation in sensor arrays, azimuth and distance estimation in synthetic aperture radar, channel estimation in wireless communication, and atom system simulation in molecular dynamics.  
In solving the spectrogram estimation problem, traditional methods include subspace methods (such as MUSIC, ESPRIT), which are based on the estimated results of the signal covariance matrix to solve for frequencies. However, they require additional model order estimation methods (such as AIC, BIC, SORTE criteria). If the model order is known, subspace methods perform well. However, when the model order is unknown, the estimation accuracy significantly drops. The random maximum likelihood (ML) method, although having asymptotic effectiveness (reaching the Cramer-Rao bound as the problem size approaches infinity), also requires known model order.
Inspired by sparse estimation and compressed sensing, a large number of line spectrum estimation algorithms based on sparsity have emerged in recent years. These methods convert line spectrum estimation into a finite sparse reconstruction problem by restricting frequencies to a grid, thereby automatically estimating the model order, avoiding the issue of model order estimation separated from frequency in traditional methods. However, grid resolution leads to a complex trade-off between precision and computational complexity. To address this, researchers proposed grid-free compressed sensing methods that ensure frequency recovery under noisy conditions and satisfy minimum separation conditions. Despite this, even for moderately large problems, the computational load remains excessive.
Some studies have approached the problem from a Bayesian perspective, introducing sparse priors into stochastic ML models, achieving automatic estimation of model order. These algorithms achieve high estimation accuracy but suffer from cubic growth in iteration complexity with the number of sinusoidal components per iteration, leading to a significant increase in running time when component counts increase.
To address these issues, this paper proposes an ultra-fast line spectrum estimation algorithm (Superfast LSE) suitable for full measurement vector scenarios. Based on the existing Bayesian method's modeling approach, the core innovation lies in computational optimization, incorporating ultra-fast Toeplitz matrix inversion, low-complexity Capon beamforming, Gohberg-Semencul formula, and non-uniform fast Fourier transform (NUFFT). Its advantages include: automatic estimation of all model parameters including noise variance and model order, with an iteration complexity of O(N log²N) (N is the length of the observation vector), and fewer than 20 iterations, significantly reducing computation time compared to existing methods in large-scale problems without sacrificing estimation accuracy. Additionally, this paper introduces a semi-fast algorithm (Semifast LSE) suitable for incomplete measurement vector scenarios, with an iteration complexity of O(NÎK²+N log N) (ÎK is the estimated number of sinusoidal components), and fewer than similar algorithms in convergence iterations.
